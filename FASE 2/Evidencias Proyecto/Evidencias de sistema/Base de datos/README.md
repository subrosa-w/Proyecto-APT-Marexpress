# Base de datos

Base MySQL 8 `marexpress_db`, con 43 tablas.

- `marexpress_db.sql`: script exportado de la base, con tablas, claves, procedimientos y triggers.
- `Modelo Base de datos Marexpress.mwb`: modelo en MySQL Workbench.
- `Modelo Base de datos Marexpress.png`: diagrama del modelo.
- El esquema implementado está en `../Aplicación/backend/prisma/schema.prisma`.
- Los scripts de columnas y datos de prueba están en `../Aplicación/backend/scripts/`.
